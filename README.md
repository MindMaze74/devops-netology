## Описание файла .gitignore

В репозитории используется файл `.gitignore`, настроенный для работы с Terraform. Он игнорирует следующие типы файлов:

- `*` — любое количество любых символов (кроме `/`).  
  Пример: `*.tfstate` — все файлы с расширением `.tfstate`.
- `**` — любое количество любых символов, включая `/`.  
  Пример: `**/.terraform/` — папки `.terraform` на любой глубине.
- `/` в конце — правило применяется к **директории**.  
  Пример: `.terraform/` — вся папка `.terraform`.
- `/` в начале — правило применяется только к файлам/папкам в **корне**.  
  Пример: `/crash.log` — только файл в корне, не в подпапках.
- `!` в начале — **отменяет** игнорирование.  
  Пример: `!example_override.tf` — этот файл будет добавлен в репозиторий.
- `#` — **комментарий**. Всё после `#` в строке игнорируется.

Таким образом, в репозитории сохраняются только исходный код Terraform (`.tf` файлы) и общие конфигурации, а всё, что может содержать секреты или быть сгенерировано автоматически, исключается из версионного контроля.
