## Описание файла .gitignore

В файле `terraform/.gitignore` определены следующие правила (каждое из них может быть раскомментировано для активации):

| Правило | Что игнорируется |
|---------|------------------|
| `.terraform/` | Вся директория `.terraform` (содержит загруженные провайдеры и модули) |
| `*.tfstate` | Все файлы с расширением `.tfstate` (файлы состояния инфраструктуры) |
| `*.tfstate.*` | Все файлы с расширением `.tfstate.*` (резервные копии состояния) |
| `crash.log` | Файл `crash.log` (лог аварийного завершения) |
| `crash.*.log` | Все файлы вида `crash.*.log` (логи аварийных завершений) |
| `*.tfvars` | Все файлы с расширением `.tfvars` (файлы переменных, часто содержат секреты) |
| `*.tfvars.json` | Все файлы с расширением `.tfvars.json` (файлы переменных в JSON) |
| `override.tf` | Файл `override.tf` (переопределение ресурсов) |
| `override.tf.json` | Файл `override.tf.json` (переопределение ресурсов в JSON) |
| `*_override.tf` | Все файлы, заканчивающиеся на `_override.tf` |
| `*_override.tf.json` | Все файлы, заканчивающиеся на `_override.tf.json` |
| `.terraform.tfstate.lock.info` | Файл блокировки состояния (создаётся при `terraform apply`) |
| `*.tfplan` | Плановые файлы, создаваемые `terraform plan -out=tfplan` (опционально) |
| `*.dot` | Графы, создаваемые `terraform graph` (опционально) |
| `planout` | Плановые файлы перед уничтожением инфраструктуры (опционально) |
| `.terraformrc` | Файл конфигурации CLI Terraform |
| `terraform.rc` | Альтернативный файл конфигурации CLI |
| `!example_override.tf` | **Исключение:** файл `example_override.tf` **не** игнорируется, его следует добавить в репозиторий (пример переопределения) |

> **Примечание:** в оригинальном файле большинство строк начинаются с `#` (закомментированы). Для активации правила будут убраны `#` в начале строки. Строка с `!` (исключение) уже активна и не требует удаления `#`.

Таким образом, в репозитории сохраняются только исходный код Terraform (`.tf` файлы) и общие конфигурации, а всё, что может содержать секреты или быть сгенерировано автоматически, исключается из версионного контроля.
