## Описание файла .gitignore

В репозитории используется файл `.gitignore`, настроенный для работы с Terraform. Он игнорирует следующие типы файлов:

- **`.terraform/`** игнорируются все файлы в директории `.terraform` (содержит загруженные провайдеры и модули).
- **`*.tfstate` и `*.tfstate.*`** игнорируются все файлы состояний Terraform (включая бекапные копии).
- **`crash.log` и `crash.*.log`** игнорируются логи аварийных завершений Terraform.
- **`*.tfvars` и `*.tfvars.json`** игнорируются файлы с переменными окружения (часто содержат чувствительные данные: пароли, ключи).
- **`override.tf`, `override.tf.json`, `*_override.tf`, `*_override.tf.json`** игнорируются файлы переопределения ресурсов (используются для локального тестирования).
- **`.terraform.tfstate.lock.info`**  игнорируются временные файлы блокировки состояния (создаются при применении `terraform apply`).
- **`.terraformrc` и `terraform.rc`**  игнорируются конфигурационные файлы CLI Terraform.

Таким образом, в репозитории сохраняются только исходный код Terraform (`.tf` файлы) и общие конфигурации, а всё, что может содержать секреты или быть сгенерировано автоматически, исключается из версионного контроля.
